# v0.1.0-rc1 — Initial Android 15 Packaging Preview

**狀態：文件型 RC 里程碑；不提供 APK 附件。**

本版根據既有 Xperia 中文鍵盤 `28.3.A.0.3` 的第三方移植 APK，完成顯示名稱與版本中繼資料調整，並驗證重新封裝的 APK 檔案完整性。

## 變更
- 名稱：`Xperia中文鍵盤(Android 15-rc)`（含 67 個語系標籤參照）。
- `versionName=28.3.A.0.3-Android15-rc`；`versionCode=59113476`。
- 保留 `com.sonyericsson.textinput.chinese`、`minSdkVersion=26`、`targetSdkVersion=28`。
- 沒有修改 `classes.dex`、注音引擎、原生函式庫或詞庫。

- ZIP CRC：PASS。
- JAR/APK v1 簽章：PASS（**公開 Android 測試憑證，非官方簽署**）。
